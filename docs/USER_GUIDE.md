# Пайдаланушы нұсқаулығы

## Талаптар
- JDK 17 немесе одан жоғары
- Maven 3.8 немесе одан жоғары

## Іске қосу
Жоба түбіріндегі терминалда командаларды орындаңыз.

```bash
mvn clean test
mvn exec:java
```

Бірінші іске қосылғанда `baseline.txt` автоматты түрде жасалады. Ол `monitored/` ішіндегі файлдардың бастапқы SHA-256 хэштерін сақтайды.

Келесі іске қосуларда жүйе baseline-ды жүктеп, каталогты қайта тексереді.

## Өзгерістерді көрсету
1. `monitored/important-document.txt` файлын ашып, ішіндегі мәтінді өзгертіңіз.
2. `monitored/` ішіне жаңа `.txt` файл қосыңыз.
3. `monitored/system-config.txt` файлын өшіріңіз.
4. `mvn exec:java` командасын қайта орындаңыз.

Есепте `MODIFIED`, `NEW` және `DELETED` мәртебелері көрінеді. Өзгермеген файл `SAFE` деп белгіленеді.

## Baseline-ды қайта құру
Егер файлдардың қазіргі күйін жаңа сенімді бастапқы күй ретінде бекіту қажет болса:

```bash
mvn exec:java -Dexec.args="init"
```

**Ескерту:** `init` ескі baseline-ды жаңасымен ауыстырады. Оны тек әдейі жаңа бастапқы күй орнатқанда пайдаланыңыз. Қалыпты тексеру baseline-ды өзгертпейді.

## Мәртебелер
- `SAFE` — файлдың SHA-256 хэші бастапқы хэшпен бірдей.
- `MODIFIED` — файлдың хэші өзгерген.
- `NEW` — файл baseline жасалғаннан кейін қосылған.
- `DELETED` — baseline ішінде болған файл қазір табылмады.
- `ERROR` — файлды оқу кезінде қате болды.

## Шектеулер
Қазіргі нұсқа каталогты команда берілген кезде сканерлейді. Ол файлдарды фондық режимде үздіксіз бақыламайды. `WatchService`, SQLite және JavaFX келесі даму кезеңдеріне жоспарланған. Baseline файлын сенімді жерде сақтау және оны рұқсатсыз өзгертуден қорғау қажет.
